# Courier Analytics Pro — Android-приложение

Проект для Android Studio: ваш HTML (`app/src/main/assets/www/index.html`) внутри WebView.
Страница открывается по `https://appassets.androidplatform.net/`, поэтому localStorage, IndexedDB,
fetch (Яндекс.Диск, погода) работают как в обычном браузере.

## Как получить APK

### Вариант 0 — один клик на Windows
Запустите `build-apk.bat`. Он сам скачает JDK 17, Android SDK и Gradle в папку `.toolchain` и соберёт `CourierAnalyticsPro.apk` в корне проекта. Нужны Windows 10+ и интернет.

### Вариант 1 — Android Studio (на компьютере)
1. Распакуйте архив, в Android Studio: **File → Open** → папка `CourierAnalyticsPro`.
2. Дождитесь Gradle Sync (нужен интернет; Studio сама скачает Gradle 8.9 и SDK 35).
   Если Studio предложит обновить Android Gradle Plugin — соглашайтесь.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk` — скопируйте на телефон и установите
   (разрешите установку из неизвестных источников).

### Вариант 2 — без Android Studio, через GitHub
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Вкладка **Actions → Build APK → Run workflow** (или просто push в main).
3. Через 3–5 минут скачайте APK из **Artifacts** (`CourierAnalyticsPro-apk`).

## Что сделано в приложении
- `alert / confirm / prompt` показываются нативными диалогами (без этого удаление и импорт не работали бы).
- Импорт файлов (`<input type="file">`) и выбор фона — через системный выбор файла.
- Экспорт CSV и других файлов — системный диалог «Сохранить как…».
- Месячный отчёт открывается в отдельном окне с кнопкой «Печать / PDF».
- Уведомления-напоминания работают через нативные уведомления Android (разрешение запрашивается).
- Внешние ссылки (Яндекс OAuth) открываются в браузере.
- Поддержка вырезов/жестов, клавиатуры, вибрации, кнопки «Назад».

## Важно знать
- **Данные из браузера не переносятся автоматически**: у приложения своё хранилище.
  Перенесите их через экспорт/импорт JSON в самом приложении или синхронизацию с Яндекс.Диском.
- Напоминания срабатывают, пока приложение открыто или недавно было свёрнуто (так устроен таймер в самой странице).
- Шрифты Inter и Material Icons подгружаются с Google Fonts: при первом запуске нужен интернет,
  дальше они кэшируются. Для полностью офлайн-работы положите файлы шрифтов в `assets/www` и подключите через `@font-face`.
- Apk подписан отладочным ключом — для личной установки этого достаточно.
  Для публикации в Google Play нужен собственный ключ и `.aab`.

## Структура
- `app/src/main/assets/www/index.html` — ваше приложение (меняйте здесь и пересобирайте)
- `app/src/main/java/com/courier/analytics/MainActivity.kt` — оболочка WebView
- `.github/workflows/build-apk.yml` — облачная сборка APK
